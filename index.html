Connect your Supabase project

Accounts, matchmaking and live games run on Supabase. Add your project credentials to config.js next to this file, then reload.

window.SHOGI_CONFIG = { SUPABASE_URL: "https://xxxx.supabase.co", SUPABASE_ANON_KEY: "eyJhbGciOi..." };

Find both under Project Settings → API. The anon key is safe to expose — Row Level Security protects your data.
