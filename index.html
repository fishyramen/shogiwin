This app runs on Supabase for real accounts, matchmaking and live games. Add your project credentials to config.js, then reload.

1 · Run the schemaExecute supabase.sql in the Supabase SQL Editor.
2 · Enable email authAuthentication → Providers → Email. Turn off “Confirm email” while testing.
3 · Fill config.jsPaste your Project URL and anon key from Settings → API.
4 · Serve over HTTPUse a local server so auth redirects resolve correctly.
